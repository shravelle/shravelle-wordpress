=== Shravelle Monitoring ===
Stable tag: 1.0.0
License: MIT

Real user monitoring and PHP error reporting for WordPress, sent to your own Shravelle server.

== Installation ==
1. Zip this folder (shravelle/) and upload it in Plugins → Add New → Upload Plugin, or copy it to wp-content/plugins/.
2. Activate "Shravelle Monitoring".
3. Settings → Shravelle: enter the ingest endpoint, browser key and ingest key from Shravelle → Settings → API keys.
